# Phase 3 changelog

## 0.3.0-alpha01

- Added AlarmManager-based PastelCal reminder engine.
- Added notification permission handling and reminder notification channel.
- Added snooze and one-time-task completion notification actions.
- Added reminder rebuild receiver for reboot/timezone/time/app-update events.
- Added recurrence calculation engine with non-duplicated database storage.
- Added recurrence expansion to Today/month agenda/month indicators.
- Added persistent appearance and planning settings.
- Added System/Light/Dark and optional Material You theming.
- Added compact month layout, ISO week numbers, and Monday-start option.
- Added writable device-calendar discovery and selected export destination.
- Added resizable native agenda home-screen widget.
- Widget and alarms now refresh automatically after Room changes.
