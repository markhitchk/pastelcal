# Phase 4 changelog

## 0.4.0-alpha01

- Added Month / Day / 3-Day / Week calendar view switcher.
- Added long-press drag rescheduling with 15-minute snapping.
- Added per-occurrence completion for recurring tasks.
- Added Room v1→v2 non-destructive migration.
- Added multiple reminder offsets per calendar item.
- Updated AlarmManager scheduling for multiple reminders and recurring-task completion.
- Added recurring-task Done support from notifications.
- Added persistent reminder notification history with pruning.
- Added ICS VEVENT/VALARM import and export.
- Added PastelCal JSON backup and replace-data restore flow.
- Added widget pastel color, transparency, text-size, and completed-task preferences.
- Updated Android Calendar Provider export to write all reminder offsets.
- Updated widget rendering to respect recurring occurrence completion.
