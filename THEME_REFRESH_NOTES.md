# PastelCal theme refresh

- Added 8 persistent accent color choices: Lavender, Sky, Mint, Peach, Pink, Butter, Blue, and Teal.
- Choosing a PastelCal accent turns off Material You so the selected accent is immediately visible.
- Added a stronger settings appearance preview and clearer branding in the app bar.
- Reworked the launcher icon for higher contrast and easier visibility.
- Removed automatic starter/demo entries. A fresh install now starts with an empty calendar and task list.
- Existing user-created data is not cleared or modified.
